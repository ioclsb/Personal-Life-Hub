## 人生进度页面

页面支持按年份记录城市、重要记录和成长经历，并提供年份标记、星标和编辑功能。

成长经历保存在浏览器本地 `localStorage`，存储键为 `personal-life-hub-life-timeline-v1`。

当前数据只保存在浏览器本地，尚未接入云端同步。迁移到小程序前，需要增加数据导出导入或云数据库方案。
